# 松岡 奏磨 (Soma Matsuoka) — Portfolio

滝学園 高校2年生・先進技術研究部 部長 松岡奏磨のポートフォリオサイトです。

## 概要

長月祭公式Webアプリ（PWA）をはじめとするWebアプリケーション開発・プロジェクトリード・UI/UXデザインなどの実績と技術スタックを掲載しています。

## 技術スタック

- **Framework**: [Next.js](https://nextjs.org/) (App Router) / [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)

## 開発環境の起動

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて確認できます。

## ビルド

```bash
npm run build
npm run start
```
